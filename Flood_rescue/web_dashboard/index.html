Adaptive PID demonstration: Select any boat using the buttons above, or click a boat directly on the flood map. When flood-water movement becomes stronger or changes more rapidly, the water disturbance and severity values change. The adaptive PID scheduler then changes the PID gains. The dashboard displays the live Kp, Ki and Kd values together with the boat's tracking error, speed, heading, thruster commands and water conditions.
Boat stabilization: the additional yaw-rate damping term opposes unwanted rotation and is added to the existing heading PID output. Stabilization effort is shown as the absolute corrective torque divided by the configured stabilizer torque limit. It indicates controller effort, not a percentage of disturbance eliminated. Compare heading error and yaw rate under matched disturbances to evaluate actual improvement.
