# Dynamic Flood Rescue Boat Simulation

## Overview

The **Dynamic Flood Rescue Boat Simulation** is a MATLAB-based project designed to simulate autonomous boat navigation and victim rescue in a dynamic flood environment. It combines path-planning algorithms, boat dynamics, feedback control, and dashboard visualization to support navigation under changing environmental conditions.

## Key Features

- **Multiple Rescue Boats:** Simulates four boats operating in a flood environment.
- **Path Planning:** Implements A*, ARA*, and RRT-based path-planning approaches.
- **Dynamic Environment:** Models moving debris, victims, wind, and water-current disturbances.
- **Drone-Assisted Victim Detection:** Uses drone-assisted detection to identify victims.
- **Dynamic Replanning:** Updates boat paths when environmental conditions or rescue priorities change.
- **Adaptive PID Control:** Controls boat heading and movement to follow the planned path.
- **Yaw-Rate Stabilization:** Adds a damping feedback term to the steering command to oppose unwanted boat rotation.
- **Differential Thrust:** Uses left and right thruster commands to control boat movement.
- **Collision Avoidance:** Supports navigation around obstacles and other boats.
- **Interactive Dashboard:** Visualizes simulation status, controller metrics, and performance graphs.

## Algorithms and Control

### 1. Path-Planning Algorithms

The project explores three path-planning approaches.

- **A\* Algorithm:** Finds a path using the accumulated cost and a heuristic estimate of the remaining cost.
- **ARA\* Algorithm:** Uses anytime heuristic search to find an initial path and refine the solution.
- **RRT-Based Planning:** Explores the environment by building a tree of reachable states to identify a path.

These algorithms provide different approaches to planning routes through the simulated flood environment.

### 2. Adaptive PID Controller

The Adaptive PID controller generates steering commands using the boat's heading error and controller feedback. It helps the boat follow the desired path while responding to changes in the environment.

The general PID control equation is:

$$
u(t)=K_p e(t)+K_i\int_0^t e(\tau)\,d\tau+K_d\frac{de(t)}{dt}
$$

Where:

- \(u(t)\) is the control output.
- \(e(t)\) is the control error.
- \(K_p\) is the proportional gain.
- \(K_i\) is the integral gain.
- \(K_d\) is the derivative gain.

The actual controller implementation may use adaptive gains and additional constraints.

### 3. Yaw-Rate Stabilization

An additional yaw-rate damping term is incorporated into the existing steering controller to oppose unwanted rotational motion of the rescue boat.

**Yaw-rate stabilization torque:**

$$
\tau_{\text{stab}}=-K_{\text{yaw}}\,r
$$

**Combined steering control command:**

$$
\tau_{\text{cmd}}=\tau_{\text{PID}}+\tau_{\text{stab}}
$$

Where:

- \(\tau_{\text{stab}}\) is the stabilization torque.
- \(K_{\text{yaw}}\) is the yaw-rate damping gain.
- \(r\) is the boat's yaw rate.
- \(\tau_{\text{PID}}\) is the torque command generated by the existing PID controller.
- \(\tau_{\text{cmd}}\) is the combined steering torque command.

The negative sign indicates that the damping torque acts opposite to the current yaw rate. This feedback is intended to reduce unwanted rotation and improve heading stability.

The stabilization term supplements the existing controller; it does not replace the PID controller or the path-planning algorithm.

### 4. Stabilization Evaluation

The controller can be evaluated using the following metrics:

- **Heading Error:** The angular difference between the desired heading and the actual heading.
- **Yaw Rate:** The rate at which the boat rotates around its vertical axis.
- **Stabilization Effort:** The magnitude of the damping correction relative to its configured torque limit.
- **Oscillation:** Repeated variations in heading or rotational motion.
- **Settling Time:** The time required for the heading error and rotational response to settle after a disturbance.
- **Path-Tracking Error:** The difference between the planned path and the boat's actual trajectory.

To determine whether stabilization improves performance, compare the original controller with the controller containing yaw-rate damping under the same initial conditions and environmental disturbances. Lower heading error, reduced yaw-rate oscillations, and improved settling behavior can indicate better stabilization.

**Note:** Stabilization improvement should be confirmed through simulation results rather than assumed from the presence of the damping term alone.

## Dashboard Metrics

The dashboard provides visual access to the simulation data and available controller metrics.

Depending on the selected implementation, the dashboard may display:

- Boat position and movement
- Planned paths
- Heading error
- Yaw rate
- Stabilization effort percentage
- Simulation status and performance graphs

**Understanding stabilization effort:** This percentage represents the magnitude of the stabilization torque relative to the configured torque limit. It measures controller effort, not the percentage of disturbance removed or the overall stability achieved.
